What the footer means

Four values at the bottom of every page. Where a page has not been stamped, the digest row is missing rather than filled with a number nobody computed.

Chain-of-custody footer — field by field
FieldWhat it isWhat this does not establish
PAGE The canonical path of the document, as published. Not that an intermediary left the delivered page unaltered.
REVISED Date of the last substantive revision, written in the source file. Not that no edit followed it; the commit history is what can contradict me.
SHA-256 (SOURCE) A digest over the page source below the front matter, computed by a tool in the public repository and committed beside the file. Not who wrote the text, when, or whether it is true.
prior versions The commit history of that one file. Not that the history is complete; I control the repository.

Checking it without asking me

  1. git clone https://github.com/wirewalktech/forensics-wirewalk
  2. Every page at once: python3 tools/stamp.py --check, which exits non-zero and names any file whose digest does not match its body.
  3. One page, using none of my code:
    awk 'f{print} /^---$/{n++; if(n==2) f=1}' versions.html | shasum -a 256

Compare the result with the digest in that page's footer and with content_sha256 in its front matter. All three are the same string or something is wrong.

A match proves one thing. The text you are reading is byte for byte the source that was stamped.

A mismatch is usually dull. A page edited and published without the stamping run — my process failure, and the one this check exists to catch. It does establish that this is not the text that was stamped, and that someone should ask why.

What it is not

Not a timestamping authority, not notarisation, and no evidence at all about any examination or opinion of mine — those are tested by reading the method and the limits and putting questions to me. It does not protect you against me either: I compute the digest and I hold the repository. So if the wording of a published term may matter to you later, print the page or take your own clone. That is the ordinary advice about anybody's terms.
